The assets are the files that are not code: textures, models, animations, structures and sounds. The translation
files and the data files (jobs, items, level tables, loot tables, tags) are part of the code.

## Assets of the project

All the assets of the project are original work. No file copies a Mojang asset. The models refer to vanilla
textures by their id (for example `minecraft:block/spruce_log`); the game provides these textures.

| Asset | Files | Origin |
| --- | --- | --- |
| Building sign textures | `world/src/main/resources/assets/folkhold_world/textures/block/building_sign/*.png` | Generated by `tools/textures/building_signs.py` |
| Villager profession textures | `world/src/main/resources/assets/folkhold_world/textures/entity/villager/profession/*.png` | Generated by `tools/textures/villager_professions.py` |
| Faction unit model and animations | `world/src/main/resources/assets/folkhold_world/geo/entity/faction_unit.geo.json`, `animations/entity/faction_unit.animation.json` | Made with Blockbench for GeckoLib |
| Quest board model | `world/src/main/resources/assets/folkhold_world/models/block/quest_board*.json` | Generated by `tools/models/quest_board.py` |
| Village structures | `world/src/main/resources/data/folkhold_world/structure/village/*.nbt` | Generated by `tools/structures/village.py` |
| Test structures | `world/src/main/resources/data/folkhold_world/structure/arena.nbt`, `empty.nbt` | Generated by `tools/make_test_structure.py` |
